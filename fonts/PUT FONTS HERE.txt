nothing left to copy in.

  Poppins-Regular.ttf          Google Fonts, OFL
  Raleway-Regular.ttf          Google Fonts, OFL
  Roboto-Regular.ttf           Google Fonts, OFL
  NotoMono-Regular.ttf         actually Noto Sans Mono (Google renamed the
                                family; kept the old filename to match the
                                UI's "Noto Mono" option), Google Fonts, OFL
  ink-free.ttf                 NOT the real Ink Free — see below
  Excalifont-Regular.ttf       hand-drawn, Excalidraw's signature font
  Nunito-Regular.ttf           Excalidraw's regular-text font
  LilitaOne-Regular.ttf        Excalidraw's bold-heading font
  ComicShannsMono-Regular.ttf  Excalidraw's code/playful font

The Excalidraw four are sourced directly from Excalidraw's official npm
package (@excalidraw/excalidraw); the rest from Google Fonts' official
repo. All under open licenses (OFL) that permit redistribution. Verified
to render Romanian diacritics (ă, â, î, ș, ț) correctly — except Lilita
One, which doesn't support ș/ț even in Excalidraw's own release; the app
falls back to a plain sans-serif for any character it's missing rather
than showing a broken glyph box.

About ink-free.ttf: 'Ink Free' ships with Windows and is Microsoft's
font — it can't legally be bundled here. The @font-face rule in
editor.html tries local('Ink Free') / local('Inkfree') first, so anyone
with the real font installed (most Windows machines) gets it for real.
This file is the fallback everyone else gets: Patrick Hand (OFL), a
plain-print handwriting look-alike, not the genuine Ink Free. If you
have a legally-obtained copy of the actual Ink Free and want pixel-exact
rendering everywhere, replace this file with it — the filename and
@font-face rule don't need to change.
